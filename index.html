bermuda-youtube-upload

버뮤다픽쳐스(Bermuda Pictures) 내부 업로드 도구

이 앱은 버뮤다픽쳐스가 제작한 영상을 자사 유튜브 채널 「버뮤다픽쳐스 BermudaPictures」에 올리기 위해 만든 내부 도구입니다. 제작자 한 사람이 자기 컴퓨터에서만 실행하며, 외부 사용자에게 제공하는 서비스가 아닙니다.

하는 일

  • YouTube Data API v3로 완성된 영상 파일, 제목, 설명, 태그, 썸네일을 채널에 업로드합니다.
  • 업로드하기 전에, 로그인한 계정의 채널이 버뮤다픽쳐스 채널인지 확인합니다.

요청하는 권한

  • youtube.upload: 영상과 썸네일 업로드
  • youtube.readonly: 업로드할 채널의 이름과 ID 확인

개인정보처리방침

bermuda-youtube-upload is an internal tool used by Bermuda Pictures to upload its own finished videos to its own YouTube channel through the YouTube Data API. It is run by a single operator on their own computer and is not offered to the public. Privacy Policy
